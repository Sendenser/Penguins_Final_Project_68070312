# Penguin Species Classifier (PyTorch MLP)

A small multilayer perceptron, built and trained from scratch in PyTorch, that predicts penguin species from physical measurements and categorical attributes.

## Task

**Input:** one penguin's measurements and attributes.
**Output:** one of 3 species: `Adelie`, `Chinstrap`, `Gentoo`.

This is multi-class tabular classification. The model is **not pretrained**: all weights are randomly initialized and learned from the data in this repo's training loop.

## Dataset

- **Palmer Penguins** (Horst, Hill & Gorman, 2020), loaded with `seaborn.load_dataset("penguins")`.
- Source: https://github.com/allisonhorst/palmerpenguins (the seaborn copy is fetched automatically on first run, so no manual download is needed).
- 344 rows originally; rows with missing values are dropped, leaving **333**.

| Feature type | Columns |
|---|---|
| Numeric (standardized) | `bill_length_mm`, `bill_depth_mm`, `flipper_length_mm`, `body_mass_g` |
| Categorical (one-hot) | `island` (3 values), `sex` (2 values) |

This gives **9 input features**.

### Splits

A random 60/20/20 split with a fixed seed (`SEED = 0`):

| Split | Size | Use |
|---|---|---|
| Train | 201 | fit weights |
| Validation | 66 | tune hyperparameters |
| Test | 66 | evaluated **once**, at the end |

Standardization (`StandardScaler`) is **fit on the training split only** and then applied to validation and test, so no information leaks from held-out data.

## Model

```
Linear(9 -> 32) -> ReLU -> Dropout(0.2)
Linear(32 -> 32) -> ReLU
Linear(32 -> 3)
```

1,475 trainable parameters. Loss: cross-entropy. Optimizer: Adam.

## Reproducing training

```bash
python train.py
```

Default hyperparameters:

| Setting | Value |
|---|---|
| Epochs | 8 |
| Learning rate | 1e-3 |
| Weight decay (L2) | 1e-4 |
| Batch size | 16 |
| Hidden units | 32 |
| Dropout | 0.2 |
| Seed | 0 |

Seeds are set for `random`, `numpy`, and `torch`, and the data split uses a seeded `torch.Generator`, so the same split and (on CPU) the same numbers should reproduce. Minor GPU nondeterminism is possible.

Training prints per-epoch train/validation loss and accuracy and shows loss/accuracy curves.

## Reproducing evaluation

```bash
python evaluate.py
```

The evaluation script:

1. Rebuilds the exact same splits and scaler from the seed.
2. Loads the trained weights (`model.pt`).
3. Prints the **majority-class baseline** for context.
4. Prints a confusion matrix and per-class recall (on validation).
5. Runs the **one-shot test evaluation** and reports final test loss and accuracy.

**Protocol:** all tuning is done on the validation set. The test set is run once, after hyperparameters are frozen, and its result is not used to make further changes.

## Key code components

- `accuracy()`, `evaluate()`: no-grad evaluation helpers
- `train()`: the standard loop (forward, loss, zero_grad, backward, step) with a validation pass each epoch, returning a history dict
- `plot_curves()`: train vs. validation curves for spotting over/underfitting
- `MLP`: the model definition
- `confusion_matrix()`: per-class error analysis
